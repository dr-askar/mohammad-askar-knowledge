Hosting und Serverprotokolle

Diese statische Website wird über GitHub Pages bereitgestellt. Anbieter ist GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA; für den europäischen Raum nennt GitHub außerdem GitHub B.V., Prins Bernhardplein 200, 1097 JB Amsterdam, Niederlande.

Beim Aufruf einer GitHub-Pages-Seite wird nach Angaben von GitHub die IP-Adresse der besuchenden Person unabhängig von einer Anmeldung zu Sicherheitszwecken protokolliert und gespeichert. Daneben können technisch erforderliche Zugriffsdaten wie Zeitpunkt, angeforderte Seite, Referrer sowie Browser- und Geräteinformationen verarbeitet werden. Die Verarbeitung erfolgt zur sicheren und zuverlässigen Bereitstellung der Website auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO. Das berechtigte Interesse liegt in der sicheren, stabilen und missbrauchsgeschützten Bereitstellung des Informationsangebots.

GitHub beschreibt Zwecke, Empfänger, internationale Datenübermittlungen und Speicherdauer in seiner Datenschutzerklärung. Weitere Hinweise zur Protokollierung bei GitHub Pages enthält die Dokumentation „What is GitHub Pages?“.

Externe Dienste

Der Websitebetreiber setzt keine eigenen Analyse-, Tracking- oder Werbedienste ein. Schriftarten, Bilder und Skripte werden lokal ausgeliefert. Externe Quellen und Profile werden lediglich verlinkt; Daten werden an deren Anbieter erst übertragen, wenn ein solcher Link aufgerufen wird. Für die Verarbeitung durch GitHub als Hostinganbieter gelten die vorstehenden Hinweise.
